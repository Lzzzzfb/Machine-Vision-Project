# 狭缝与窄平台二维夹角测量系统设计

- 日期：2026-08-05
- 状态：已获用户批准，待实现
- 目标平台：Windows 10/11，Python
- 相机：HIKROBOT MV-CS050-10UC
- 镜头：HIKROBOT MVL-MF2518M-5MPE

## 1. 背景

被测对象是放置在窄平台上的狭缝。系统需要在同一幅图像中识别一条狭缝边缘和一条平台边缘，并计算两条直线在图像平面内的较小夹角。目标完全静止，由人工放置；位置可能小幅偏移，但方向基本固定。现场从相机侧使用环形 LED 照明。

本设计同时规划一套项目知识库，将相机技术规格、USB3.0 工业面阵相机用户手册、镜头技术规格、SDK 接入、标定、安装调试和故障排查整理为便于开发期间检索的 Markdown 文档。

## 2. 设计目标

### 2.1 功能目标

1. 通过海康 MVS SDK 连接 MV-CS050-10UC，并支持软件触发采集静态图像。
2. 支持本地图片输入，使算法可在未安装 SDK 或未连接相机时开发、演示和回归测试。
3. 使用两个可旋转测量带 ROI，分别提取狭缝边缘和平台边缘。
4. 对边缘进行亚像素定位、离群点剔除和稳健直线拟合。
5. 输出 0°～90°范围内的较小夹角、拟合质量、置信度和有效/无效状态。
6. 显示原图、ROI、有效边缘点、拟合直线、理论交点和角度结果。
7. 保存原图、结果叠加图、CSV 测量记录、配置和诊断日志。
8. 提供相机标定、标定质量检查和可打印棋盘格。

### 2.2 首版质量目标

1. 已知角度的合成图像上，算法角度误差不超过 0.1°。
2. 固定目标连续测量 30 次，角度标准差不超过 0.2°。
3. 人工重新放置目标至少 10 次时记录分布，参考目标为标准差不超过 0.5°；该项用于评估工装和操作影响，不构成无条件精度承诺。
4. 连续采集和测量 500 帧不崩溃、不发生持续资源增长，采集故障可恢复。
5. 空白、过曝、欠曝、无边缘或拟合失败的图像必须返回明确的无效状态，不得给出伪角度。

### 2.3 非目标

1. 首版不测量三维空间夹角。
2. 首版不处理运动目标，不要求硬件触发或运动冻结。
3. 首版不使用深度学习，不建立训练数据集。
4. 在缺少可溯源角度标准件时，不声明系统的绝对测量准确度。
5. 首版不自动识别任意位置和任意方向的目标；允许通过较宽的测量带容忍小幅位置偏移。

## 3. 测量定义与约束

两条拟合直线的单位方向向量分别为 `d1` 和 `d2`。系统输出：

```text
angle_deg = degrees(acos(clamp(abs(dot(d1, d2)), 0, 1)))
```

绝对点积使方向相反的同一直线视为相同方向，因此结果为 0°～90°的较小夹角。两条无限延长直线的交点只用于可视化；交点不必位于图像内，也不影响角度计算。

由于狭缝边缘与平台边缘是否共面尚未确定，结果名称固定为“图像平面投影夹角”。相机光轴应尽量垂直于平台基准面。若后续确认高度差显著且需要真实三维夹角，应另行评估远心镜头、双目或三维测量方案。

## 4. 已选硬件与光学设计

### 4.1 相机

MV-CS050-10UC 的关键参数：

- Sony IMX264，2/3 英寸 CMOS，全局快门
- 2448 × 2048，像元尺寸 3.45 µm × 3.45 µm
- 最大 60 fps（2448 × 2048，Bayer RG 8）
- 动态范围 71 dB，信噪比 40 dB，增益 0～24 dB
- 超短曝光 1～14 µs，正常曝光 15 µs～10 s
- USB3.0，兼容 USB3 Vision 和 GenICam
- C-Mount，支持 USB 供电
- 支持 Mono、Bayer、RGB/BGR、ROI、软触发和硬触发

### 4.2 镜头

MVL-MF2518M-5MPE 与相机的 2/3 英寸靶面、500 万像素分辨率和 C-Mount 接口匹配。关键参数：

- 固定焦距 25 mm
- 手动光圈 F1.8～F16
- 标称畸变 0.77%
- 最近摄距 0.2 m（不加接圈）
- 手动聚焦

### 4.3 初始安装

1. 相机和镜头固定在刚性支架上，避免测量过程中移动、松动或振动。
2. 相机光轴尽量垂直平台基准面，并使两条目标边缘都落在视场中央区域。
3. 首轮调试不加接圈，工作距离从约 200 mm 开始；规格书给出的 2/3 英寸视野约为 66.1 mm × 54.8 mm。
4. 若目标在图像中占比不足，再增加 5 mm C-Mount 接圈。对应工作距离约 86～131 mm，视野约从 15.0 mm × 12.5 mm 变化到 21.6 mm × 18.1 mm。
5. 初始光圈使用 F4～F8，在景深、衍射、曝光和边缘清晰度之间现场选择。
6. 环形 LED 固定机械位置和亮度。高光明显时优先调整灯的距离与入射角，再考虑镜头偏振片或交叉偏振。

### 4.4 推荐相机参数

- 像素格式：优先 Mono 8，避免彩色插值改变几何边缘并降低处理复杂度
- 触发：软件触发；调试预览可使用自由运行
- 曝光：手动，避免测量期间自动变化
- 增益：尽可能低，通常从 0 dB 开始
- Gamma、LUT、锐化和自动白平衡：关闭
- Binning、下采样和镜像：关闭
- 分辨率：2448 × 2048；仅在性能确有需要时再评估相机 ROI

## 5. 标定设计

角度本身不需要毫米/像素换算，但需要校正镜头畸变，尤其当两条边位于画面不同区域时。

### 5.1 标定板

首版生成一个 9 × 6 内角点、10 × 7 方格、名义格距 5 mm 的可打印棋盘格。普通 A4 复印纸可用，不要求哑光专用纸，但应满足：

1. 打印选择“实际大小”或 100%，关闭“适合页面”。
2. 使用清晰的黑色墨粉或墨水，避免灰阶省墨模式。
3. 平整粘贴到玻璃、亚克力板、铝板或其他刚性平板，避免折痕、气泡和翘曲。
4. 用卡尺测量连续多个方格的总长度并计算平均实际格距，将数值记录进标定元数据。
5. 标定时若环形灯反光，可降低灯光或改用均匀的侧向环境光。

若采用 5 mm 接圈并将视野缩小到 15～22 mm，改用 1～2 mm 方格的高精度打印件或玻璃标定板。

### 5.2 采图与质量检查

1. 在最终光圈、对焦、接圈和工作距离确定后进行标定。
2. 采集约 15～25 张清晰图像，使棋盘覆盖中心、四角、边缘和多个倾斜姿态。
3. 排除运动模糊、角点过曝、棋盘明显弯曲或覆盖面积过小的图像。
4. 保存相机矩阵、畸变系数、图像分辨率、实际格距、采图数量、每图误差和整体 RMS 重投影误差。
5. 首版要求 RMS 重投影误差不超过 0.5 像素；超限时给出质量失败并提示重新采图。
6. 接圈、工作距离或对焦位置发生变化后重新标定。

程序允许在无标定文件时运行，但界面和输出记录必须明确标注“未标定”。标定文件分辨率与当前图像不一致时禁止直接应用。

## 6. 软件架构

### 6.1 技术栈

- Python 3.11
- OpenCV：标定、去畸变、图像处理和几何运算
- NumPy：数值计算
- PySide6：Windows 桌面界面
- pytest：单元测试和回归测试
- 海康 MVS SDK Python 示例封装：USB3 相机枚举、连接、参数设置和取流

若已下载的 MVS SDK 尚未安装，实现阶段从用户提供的安装包位置或解压后的 `Development`/`Samples` 目录确认实际结构。SDK 安装包、驱动和厂商二进制不提交到 Git；仓库只保存适配代码、安装说明和路径配置。

### 6.2 模块边界

1. `FrameSource`
   - 定义连接、关闭、读取单帧、开始/停止预览和读取设备信息的统一接口。
   - `MvsCameraSource` 负责海康 SDK。
   - `ImageFileSource` 负责单图和目录回放。
2. `CalibrationService`
   - 棋盘角点检测、相机标定、质量报告、文件保存/加载和图像去畸变。
3. `RecipeService`
   - 保存两个测量带 ROI、边缘极性、搜索宽度、相机参数、阈值和标定文件引用。
4. `EdgePointExtractor`
   - 在旋转测量带中建立法向扫描线，计算梯度，筛选边缘并进行亚像素定位。
5. `RobustLineFitter`
   - 使用 RANSAC 剔除异常点，再使用总最小二乘得到最终直线、残差和内点集合。
6. `AngleMeasurementService`
   - 组合两条直线、计算较小夹角、理论交点、置信度和有效性。
7. `ResultRepository`
   - 保存原图、叠加图、CSV、配置快照和诊断信息。
8. `DesktopApplication`
   - 相机控制、实时预览、ROI 编辑、标定、测量、结果展示和错误提示。

核心算法只接收 NumPy 图像和普通配置对象，不导入 MVS SDK，也不依赖界面。这保证相机、算法和 UI 可独立测试与替换。

## 7. 测量算法

### 7.1 测量带配置

每条物理边缘对应一个可旋转矩形测量带。用户沿目标边缘绘制中心线并设置带宽。配置保存：

- 中心线两个端点或等价的中心、长度和角度
- 带宽和扫描线数量/间距
- 允许的位置偏移范围
- 边缘极性：暗到亮、亮到暗或自动
- 最小梯度强度
- 预期方向容差

测量带应覆盖足够长的直线段，并避开端点、交角处、明显缺口、螺纹、刻字和持续高光区域。

### 7.2 边缘点提取

1. 获取 Mono 8 图像并进行畸变校正。
2. 仅在必要时使用轻微高斯滤波，不默认使用会改变局部对比关系的强增强操作。
3. 在每个旋转测量带内生成多条垂直于预期边缘的扫描线。
4. 沿每条扫描线计算一维灰度梯度。
5. 根据极性、梯度强度和相对位置选择候选峰，避免选择狭缝的另一条平行边或高光边。
6. 在梯度峰邻域用抛物线拟合或加权质心求取亚像素位置。
7. 为每个点保留梯度强度、边缘极性和扫描线索引，供质量评估使用。

### 7.3 稳健直线拟合

1. 使用 RANSAC 从候选点中识别主直线并排除灰尘、划痕、缺口和高光导致的离群点。
2. 使用全部 RANSAC 内点进行总最小二乘拟合，使结果不偏向水平或垂直方向。
3. 输出单位方向向量、法向量、质心、RMS 正交残差、最大残差、内点数量、内点率和有效线段跨度。

### 7.4 有效性与置信度

结果有效性至少检查：

- 每条边的有效点数量
- 有效线段长度
- 平均梯度强度
- RANSAC 内点率
- RMS 正交残差
- 拟合方向是否落在配置容差内
- 图像亮度和饱和像素比例
- 两个 ROI 是否完整位于图像内

置信度由上述指标归一化后组合，范围为 0～1。具体阈值由合成测试和首批实物图像确定，并保存到测量配方。任何强制条件不满足时，状态为无效且角度字段留空。

## 8. 用户界面与工作流

主界面包含设备与图像源、实时画面、相机参数、ROI/配方、测量结果和日志区域。典型流程：

1. 选择 MVS 相机或本地图片源。
2. 连接相机并载入已有配方，或创建新配方。
3. 调整环形灯、光圈、对焦、曝光和增益，锁定参数。
4. 加载有效标定文件；没有标定文件时显示持续警告。
5. 绘制狭缝边缘测量带和平台边缘测量带，选择边缘极性。
6. 预览候选点和拟合结果，保存配方。
7. 执行单次测量或连续测量。
8. 查看角度、置信度、两条线的残差/内点率以及叠加图。
9. 按需保存原图、结果图和 CSV。

首版支持可选的角度合格区间，但默认只显示测量有效/无效，不预设产品合格标准。

## 9. 数据与可追溯性

每条测量记录至少包含：

- 时间戳和图像编号
- 相机型号、序列号和当前分辨率
- 曝光、增益、像素格式和触发模式
- 配方名称与版本
- 标定文件标识和是否已校正
- 两条直线的方向参数
- 夹角
- 各直线有效点数、内点率、有效跨度和 RMS 残差
- 图像质量指标与综合置信度
- 有效/无效状态和失败原因
- 原图及结果图相对路径

输出按日期分目录。文件写入失败不得影响当前图像显示，但必须在界面和日志中明确提示。

## 10. 错误处理

1. MVS SDK 缺失：显示安装和路径说明，允许切换到本地图片模式。
2. 未枚举到相机：显示 USB、供电、驱动和 MVS 客户端排查步骤。
3. 相机连接或取帧超时：停止当前采集、释放资源并允许重新连接。
4. 参数写入失败：显示具体参数和值，不继续假定参数已生效。
5. 图像欠曝、过曝或模糊：结果无效或显示低质量警告，保留诊断图。
6. ROI 越界或分辨率不匹配：禁止测量并要求修正配方。
7. 标定缺失：允许运行但持续标记未标定。
8. 标定分辨率不匹配或文件损坏：禁止应用标定并解释原因。
9. 边缘点不足、方向不符、内点率过低或残差过大：结果无效且不返回角度数值。
10. 保存失败：保留当前结果并记录错误，不让 UI 崩溃。

## 11. 测试与验收

### 11.1 单元测试

- 方向向量和夹角计算，包括 0°、接近 0°、45°、90°和方向反转
- 旋转测量带坐标变换与图像边界
- 亚像素峰值定位
- 总最小二乘对水平、垂直和任意角度直线的一致性
- RANSAC 在噪声和离群点下的稳健性
- 配方和标定文件序列化/反序列化
- 有效性判定和置信度边界

### 11.2 合成图像测试

生成覆盖 0°～90°的双边缘图像，改变线宽、对比度、模糊、亮度、噪声、断边、遮挡和离群点。有效样本角度误差目标不超过 0.1°；不可测样本必须返回无效。

### 11.3 标定测试

- 棋盘角点覆盖中心和画面四周
- RMS 重投影误差不超过 0.5 像素
- 保存后重新载入得到相同参数
- 分辨率不一致时拒绝应用
- 去畸变前后直线残差和跨区域角度一致性有可见改善

### 11.4 实机测试

- MVS 枚举、连接、软件触发、参数写入、取帧和断线恢复
- 固定目标连续测量 30 次，标准差不超过 0.2°
- 人工重复放置 10 次并报告标准差，参考目标不超过 0.5°
- 连续运行 500 帧无崩溃和持续资源增长
- 改变亮度、制造局部反光和遮挡，检查失败诊断是否正确
- 使用已知角度标准件验证实际准确度；若无标准件，仅报告重复性和算法测试结果

## 14. 已知风险与应对

1. 两条边不共面：输出明确限定为投影夹角；严格控制相机垂直度，必要时升级远心或三维方案。
2. 环形灯高光产生伪边缘：固定曝光和灯光，调整照明几何，使用极性/方向/位置约束及 RANSAC，必要时增加偏振。
3. 狭缝的两侧边缘被混淆：每个测量带保存边缘极性和相对位置，界面显示候选点供确认。
4. 普通纸质标定板不平：粘贴到刚性平板，并通过重投影误差和单图误差剔除不合格标定。
5. 25 mm 镜头在 200 mm 工作距离下目标占比较小：先以完整视野完成系统验证，再用 5 mm 接圈提高像素利用率。
6. MVS SDK Python 文件结构因版本不同而变化：通过单独适配层和路径探测隔离差异，不复制厂商二进制进仓库。
7. 没有绝对角度标准：区分算法误差、重复性和绝对准确度，避免用重复性代替准确度声明。

## 15. 实现前需要收集的现场输入

这些信息不阻塞离线算法和界面实现，但会影响实机参数和最终验收：

- 一张或多张包含狭缝边缘、平台边缘和环形灯实际效果的原始相机图像
- MVS SDK 的版本、安装状态和本机路径
- 相机序列号与当前固件版本
- 实际工作距离、是否使用接圈、最终光圈和对焦位置
- 两条边的大致高度差和材质反光情况
- 若要验证绝对准确度，可提供的已知角度标准件或参考测量方法

## 16. 设计决策摘要

- 采用两个可旋转测量带，而不是全图霍夫或轮廓外接矩形。
- 采用一维梯度亚像素定位、RANSAC 和总最小二乘拟合。
- 采用 MVS 相机源与本地图像源统一接口，使开发不受硬件可用性限制。
- 默认软件触发、Mono 8、手动曝光和低增益。
- 标定为正式测量推荐步骤，但允许带明显警告的未标定运行。
- 首版专注静态二维投影夹角，拒绝将不可靠结果伪装为有效数值。
