# 双视图实时测量、界面重构与成像优化实施计划

日期：2026-08-06

依据：[设计规格](../specs/2026-08-06-dual-view-realtime-ui-optics-design.md)

## 1. 基础控件和配方

- 新增统一的无滚轮整数/浮点输入控件。
- 在质量配置中增加稳定窗口、稳定标准差、平台/狭缝模糊宽度及有效剖面阈值，旧配方使用默认值。
- 新增固定窗口稳定性统计模型及单元测试。

## 2. 清晰度和边缘定位

- 平台边缘从单点抛物线峰值改为局部对称线扩散加权中心定位。
- 为平台边缘和亮狭缝两侧边缘记录扩散宽度。
- 新增三个 ROI 的清晰/临界/不足诊断，并在不足时产生结构化失败原因。
- 增加清晰、轻度模糊、严重模糊和低对比合成测试。

## 3. 实时采集与测量

- 新增独占 MVS 相机的采集线程，连接后持续发布最新帧。
- 新增实时测量控制器，测量周期 500 ms、队列长度固定为 1。
- ROI 拖动开始时暂停测量，结束时立即测量并恢复。
- 相机参数变化通过停止采集、重建线程和恢复实时状态应用。
- 新增启停、丢帧、慢测量、稳定窗口和错误生命周期测试。

## 4. 双图像视图

- 抽取同步图像视图和双图像面板。
- 左侧仅显示原图；右侧显示处理底图和独立 ROI 图形项。
- 同步缩放、平移、适合窗口和 100%。
- ROI 项增加选择、拖动开始、实时移动和拖动结束信号。
- 叠加渲染增加 ROI/辅助线独立显隐选项。

## 5. 界面组件

- 新增紧凑顶部工具栏。
- 新增无滚动条 ROI 检查器和测量摘要。
- 新增设置窗口，集中相机、配方、标定、高度和输出路径。
- 重构主窗口，使其只协调组件、帧、测量任务和持久化。
- 使用 Qt 设置保存界面显隐和常用路径。

## 6. 保存与文档

- 移除实时逐帧自动保存，增加“保存当前结果”。
- JSON/CSV 增加稳定统计、清晰度、曝光、增益和测量刷新率。
- 更新操作指南，记录 F8、抬高 50～100 mm、中间焦点、450 ms 和低增益调试流程。

## 7. 验证与提交

- 运行完整单元、合成、集成和 GUI 测试。
- 离线运行三 ROI 20° 示例并检查保存文件。
- 检查 1920×1080 构造、无主滚动条、双视图同步和退出生命周期。
- 提交实现并推送 `origin/main`。
