# 亮狭缝—平台双平面测量实施计划

日期：2026-08-06

依据：[双平面测量规格](../specs/2026-08-05-bright-slit-platform-dual-plane-design.md)

## 实施顺序

1. 配方升级为版本 2：亮狭缝中心、平台长边 1、平台长边 2、高度差和质量阈值；加载版本 1 时迁移并要求复核第三个 ROI。
2. 标定文件升级为版本 2：保留内参并增加平台 `solvePnP` 姿态；增加 `angle-calibrate-pose` 命令。
3. 新增亮线成对边缘中心提取器，复用 RANSAC/TLS 完成狭缝中心线拟合。
4. 分别拟合平台双边，检查 ROI 分离和平行度，建立平均平台方向。
5. 将去畸变像素射线分别与平台平面和高度偏移平面求交，在平台 XY 坐标系重新拟合并计算补偿角度。
6. GUI 增加三 ROI、亮线参数、高度/姿态状态、投影诊断角、平行度以及缩放和平移。
7. CSV/JSON 和叠加图扩展为三条图像线、三条世界线及补偿诊断数据。
8. 使用亮线单元测试、双平面透视合成测试、CLI 集成测试和 GUI 冒烟测试验证。

## 完成标准

- 缺少高度或平台姿态时不得输出正式角度。
- 合成透视场景中的已知世界夹角恢复误差不超过 0.15°。
- 平台双边覆盖同一边或平行度超限时返回结构化失败。
- 图像缩放和平移不改变 ROI 图像坐标和测量结果。
- 完整测试集通过，示例配方和操作文档与版本 2 一致。
