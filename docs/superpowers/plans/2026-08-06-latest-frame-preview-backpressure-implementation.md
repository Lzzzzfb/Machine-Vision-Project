# 最新帧预览背压修复实施计划

日期：2026-08-06

依据：[修复设计](../specs/2026-08-06-latest-frame-preview-backpressure-design.md)

## 1. 采集线程

- 将携带完整帧的 `frame_ready(Frame)` 改为无负载 `frame_available()`。
- 增加锁、最新帧槽和通知挂起标志。
- 新帧只替换槽内容；已有通知挂起时不重复发送。
- 提供线程安全的 `take_latest_frame()`，领取最新帧并重新允许下一次通知。
- 帧率计算保持不变，状态信号最多每 500 ms 发送一次。

## 2. 主窗口

- 连接 `frame_available()` 到新的领取槽。
- 只领取当前活动采集线程的最新帧，忽略旧线程迟到通知。
- 领取后继续使用现有 `_frame_received()` 更新原图、帧号和实时控制器。

## 3. 测试

- 新增采集线程发布单元测试：突发帧只发一个通知、领取得到最后帧、领取后可再次通知。
- 增加主窗口旧线程通知保护测试。
- 运行完整自动化测试和全分辨率突发压力测试。
- 关闭正在运行的旧版 UI 后，用 MV-CS050-10UC 做连接、单次测量和实时测量实机验收。
