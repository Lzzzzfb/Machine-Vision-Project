# 操作指南

## 1. 光学与零件摆放

1. 相机尽量垂直于矩形底座，支架锁紧。
2. 在当前 F4 安装位置基础上先把相机抬高约 50 mm；仍无法同时清晰时逐步增加，总调整量控制在约 50～100 mm。
3. 将光圈调到 F8，增益从 0 dB 开始，尽量不超过 6 dB。
4. 焦点调在圆柱顶部狭缝面与底座长边参考面之间，使两个高度平面的清晰度尽量均衡。
5. 调整曝光，使两个目标都有足够对比且不过曝；为了维持约 2 Hz 测量，曝光尽量不超过 450000 µs。
6. 放大检查顶部狭缝和底座边缘是否同时清晰。F8 仍不能满足景深时才对比 F16；F16 可能因衍射降低边缘定位能力，不能只凭肉眼采用。
7. 锁紧镜头焦点和光圈后重新标定；之后不得移动相机、镜头或参考平面。

现有环形灯已经开到最大时，如果 F8、450 ms、6 dB 仍明显欠曝，应增加更强的漫射照明或均匀照亮底座背景，而不是继续拉高增益。平台边缘应依靠黑色底座与均匀背景的轮廓对比形成。

## 3. 主界面与图像操作

- 左侧“原始采集图”始终保持纯净，不显示 ROI、辅助线或结果文字。
- 右侧“测量结果图”显示处理结果，并且只有这一侧可以选择和拖动 ROI。
- 两幅图的滚轮缩放和平移同步；“适合窗口”显示整幅图，“100%”按原像素显示。
- 两个标题分别显示原图帧号和结果帧号。实时取流时二者可能暂时不同，这是最新原图与上一测量结果的正常状态。
- “显示 ROI”和“显示辅助线”可独立开关，只影响显示和手动保存的叠加图，不改变算法结果。
- 所有数值输入框均不会被滚轮误改；仍可键盘输入或使用上下箭头。

## 4. 配置三个 ROI

1. 橙色“亮狭缝中心线”：沿黑色圆柱顶部的亮线放置，宽度只包住亮线及两侧少量暗背景。
2. 青色“平台长边 1”：覆盖矩形底座第一条长外边的干净直线段。
3. 紫色“平台长边 2”：覆盖另一条长外边的对应直线段。

平台 ROI 必须避开圆柱、四个安装孔、短边、圆角/倒角及右侧缺口。两个平台 ROI 应尽量长且互相分离。平台边缘极性可选“自动”“暗到亮”或“亮到暗”；狭缝 ROI 使用亮线最小对比度及最小/最大宽度参数。

点击或拖动处理图中的 ROI 后，右侧检查器会自动切换到对应项目，中心坐标在拖动时实时更新。拖动期间算法暂停，松开后立即用最新帧重测。数值输入会立即更新处理图中的 ROI。需要长期保留时，进入“设置”并使用“另存当前配方”。旧版本配方加载后，平台长边 2 会复制长边 1，必须重新放置并确认。

## 5. 高度与标定

点击工具栏“设置”，在“狭缝高度差”填写从矩形底座长边所在参考平面到圆柱顶部实际狭缝平面的垂直距离，单位 mm。不要填写零件到桌面的总高度。

按照[标定指南](calibration.md)先生成相机内参，再生成包含平台姿态的版本 2 标定文件，然后在“设置”中加载。改变工作距离、光圈、焦点或相机安装姿态后必须重新标定。

## 6. 测量与结果

- “补偿夹角”：正式双平面角度。
- “投影诊断角”：未做高度补偿的图像夹角，只用于调试。
- “平台双边平行度”：两条长边的质量校验，默认不得超过 1°。
- 红色“无效”：正式角度显示 `--`，按状态文字排查。

连接相机后，左侧原图会持续刷新。“单次测量”处理当前最新帧；“实时测量”约每 500 ms 处理当时的最新帧，算法忙时跳过旧帧，不产生队列积压。

稳定性窗口包含最近 10 次测量尝试。10 次全部有效且样本标准差不超过 0.1°时显示“稳定”；调整 ROI、配方、高度或标定后会重新累计。三个 ROI 的“清晰/临界/不足”分别显示，任何一个“不足”都会拒绝正式结果。

实时模式不自动保存每帧。需要记录时点击“保存当前结果”，程序仅保存一次当前纯净原图、按当前显隐状态生成的叠加图、JSON 和 CSV。保存字段包含三处清晰度、10 次稳定性、曝光、增益、采集帧率和测量刷新率；无效结果也可以保存用于排障。

## 7. 推荐的首次实机流程

1. 抬高相机 50 mm，设置 F8，环形灯保持当前最大亮度。
2. 在“设置”中先用 0 dB、适中曝光连接相机；必要时逐步提高曝光，优先把增益限制在 6 dB 内。
3. 开启“实时测量”，放大两个视图，把焦点调到两层之间，直到三个 ROI 至少都不是“不足”。
4. 依次拖动橙、青、紫三个 ROI 到亮狭缝和底座两条长边的干净直线段。
5. 锁紧光圈、焦点和支架，重新进行内参及平台姿态标定，测量并录入固定高度差。
6. 固定零件连续测量至少 30 次，记录中位数、标准差、极差及无效率；确认重复性后再把当前配方另存为正式配方。

## 8. 命令行批处理

```powershell
angle-measure data/input --recipe configs/example_recipe.json `
  --calibration calibration/camera-with-pose.json --output data/output
```

每张图输出一行 JSON。全部有效时退出码为 0；存在无效测量时为 1；配置或输入错误时为 2。
