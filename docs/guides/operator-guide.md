# 操作指南

## 1. 光学与零件摆放

1. 相机尽量垂直于矩形底座，支架锁紧。
2. 不加接圈时先从约 200 mm 工作距离、F8、0 dB 增益开始。
3. 调整环形灯和曝光，使圆柱顶部亮狭缝清楚，同时底座两条长外边不过曝。
4. 放大检查顶部狭缝和底座边缘是否同时清晰。景深不足时优先增加工作距离或收至 F11；不要默认使用 F16。
5. 锁紧镜头焦点和光圈后再标定；之后不得移动相机、镜头或参考平面。

## 2. 启动

```powershell
cd D:\codex\机器视觉系统\角度测量
.\.venv\Scripts\Activate.ps1
angle-gui
```

也可直接运行：

```powershell
.\.venv\Scripts\python.exe -m angle_measurement.ui.launcher
```

## 3. 图像操作

- 鼠标滚轮：以指针位置为中心缩放。
- 在空白处拖动：平移图像。
- “适合窗口”：显示整幅图。
- “100%”：一个图像像素对应一个显示像素。
- “放大/缩小”：按固定倍率调整。
- 拖动彩色 ROI 只改变 ROI 图像坐标，不受当前缩放倍率影响。

## 4. 配置三个 ROI

1. 橙色“亮狭缝中心线”：沿黑色圆柱顶部的亮线放置，宽度只包住亮线及两侧少量暗背景。
2. 青色“平台长边 1”：覆盖矩形底座第一条长外边的干净直线段。
3. 紫色“平台长边 2”：覆盖另一条长外边的对应直线段。

平台 ROI 必须避开圆柱、四个安装孔、短边、圆角/倒角及右侧缺口。两个平台 ROI 应尽量长且互相分离。平台边缘极性可选“自动”“暗到亮”或“亮到暗”；狭缝 ROI 使用亮线最小对比度及最小/最大宽度参数。

调整后点击“应用 ROI 参数”，再另存配方。旧版本配方加载后，平台长边 2 会复制长边 1，必须重新放置并确认。

## 5. 高度与标定

“狭缝高度差”填写从矩形底座长边所在参考平面到圆柱顶部实际狭缝平面的垂直距离，单位 mm。不要填写零件到桌面的总高度。

按照[标定指南](calibration.md)先生成相机内参，再生成包含平台姿态的版本 2 标定文件。GUI 中“标定”和“平台姿态”均应显示绿色。

## 6. 测量与结果

- “补偿夹角”：正式双平面角度。
- “投影诊断角”：未做高度补偿的图像夹角，只用于调试。
- “平台双边平行度”：两条长边的质量校验，默认不得超过 1°。
- 红色“无效”：正式角度显示 `--`，按状态文字排查。

静态正式记录建议点击一次“采集并测量”。“连续测量”用于调焦、调灯和观察稳定性。勾选自动保存后，程序保存原图、叠加图、逐帧 JSON 和 CSV。

## 7. 命令行批处理

```powershell
angle-measure data/input --recipe configs/example_recipe.json `
  --calibration calibration/camera-with-pose.json --output data/output
```

每张图输出一行 JSON。全部有效时退出码为 0；存在无效测量时为 1；配置或输入错误时为 2。
