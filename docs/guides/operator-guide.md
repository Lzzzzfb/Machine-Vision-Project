# 操作指南

## 首次配置

1. 安装 Python 依赖和海康 MVS SDK。
2. 在 MVS 客户端中确认相机、镜头、环形灯和 USB3 驱动正常。
3. 锁定工作距离、光圈、焦点、曝光和增益。
4. 打印棋盘格并完成标定。
5. 打开一张典型目标图片，分别放置狭缝和平台测量带。
6. 选择正确的边缘极性，保存测量配方。

## 图形界面

启动：

```powershell
angle-gui
```

- 本地图片：点击“打开图片”，调整两个测量带，点击“测量当前图像”。
- MVS 相机：输入曝光和增益，点击“连接 MVS”，再点击“采集并测量”。
- 测量带可在图像中拖动；长度、宽度和角度在右侧面板精确设置。
- “连续测量”适合观察稳定性；静态正式记录建议使用单次软件触发。
- 勾选自动保存后，程序按日期保存原图、结果图和 CSV。

## 结果状态

- 绿色“有效”：两条直线均通过点数、跨度、内点率和残差检查。
- 红色“无效”：查看具体失败原因；角度显示为 `--`。
- “未标定”：算法可运行，但结果没有经过镜头畸变校正，不应用于正式准确度判断。

## 命令行批处理

```powershell
angle-measure data/input --recipe configs/example_recipe.json --calibration calibration/camera.json --output data/output
```

每张图输出一行 JSON。全部有效时退出码为 0；存在无效测量时为 1；配置或输入错误时为 2。
