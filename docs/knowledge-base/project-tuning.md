# 角度测量项目现场调试

## 1. 固定机械和光学条件

1. 刚性固定相机，光轴尽量垂直平台基准面。
2. 从不加接圈、约 200 mm 工作距离开始，使两条边和人工放置偏移均落在画面内。
3. 环形 LED 与相机固定连接，不让灯在测量之间移动。
4. 将光圈设为 F4～F8并调焦，锁紧镜头。
5. 若金属表面出现亮环或高光边，先改变灯距或角度，再考虑偏振片。

## 2. 锁定图像参数

1. MVS 中选择 Mono 8、2448 × 2048。
2. 关闭自动曝光和自动增益，Gain 从 0 dB 开始。
3. 调整曝光，使亮区不饱和、暗区保留层次、两条物理边缘清晰。
4. 关闭 Gamma、LUT、锐化、Binning、下采样和镜像。
5. 保存一张原始 PNG 作为调试基准，不使用 JPEG 有损压缩图判断亚像素精度。

## 3. 标定

完成光圈、对焦、工作距离和接圈选择后再标定。普通 A4 复印纸可以使用，但必须 100% 打印并平整贴在刚性板上。标定 RMS 应不超过 0.5 px；更换接圈或重新对焦后重做标定。

详见[标定指南](../guides/calibration.md)。

## 4. 设置两个测量带

- 测量带中心线沿真实物理边缘放置。
- 长度尽量覆盖较长、连续、无缺口的直线段。
- 宽度应容纳人工位置偏移，但不要同时覆盖多条相似平行边。
- 避开狭缝端点、平台端点、交点附近、高光、刻字和明显划痕。
- 若同一测量带内存在狭缝两侧边，选择正确的明暗极性，并收窄搜索带。

界面中可以拖动测量带；角度、长度和宽度通过参数面板精确调整。调整后保存配方。

## 5. 判断结果是否可信

有效结果同时依赖：

- 足够多的扫描线找到边缘
- 边缘点覆盖足够长的线段
- RANSAC 内点率达到阈值
- 总最小二乘 RMS 残差不超限
- 梯度强度充足
- 图像没有大面积过曝或对比度不足

无效时优先查看 `failure_reasons`，不要为了得到数值直接放宽所有阈值。建议按“图像质量 → ROI 位置/极性 → 边缘阈值 → RANSAC 阈值”的顺序排查。

## 6. 重复性检查

1. 目标和相机保持不动，连续测量 30 次。
2. 计算角度均值、标准差和极差；首版目标标准差不超过 0.2°。
3. 人工取下并重新放置 10 次，记录放置重复性；参考目标标准差不超过 0.5°。
4. 若固定测量稳定但重复放置波动大，应先改善工装定位，而不是继续调算法。
5. 绝对准确度必须用已知角度标准件验证；打印线条和重复性结果不能替代可溯源标准。
