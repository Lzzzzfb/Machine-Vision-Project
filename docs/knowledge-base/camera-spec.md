# MV-CS050-10UC 相机规格与项目参数

## 型号定位

MV-CS050-10UC 是 500 万像素、2/3 英寸、USB3.0 彩色工业面阵相机，传感器为 Sony IMX264，使用全局快门。规格书同时列出黑白型号 MV-CS050-10UM；本项目使用彩色型号 UC，注意不要混用两个型号的像素格式和功耗数据。

来源：[技术规格书 PDF 第 1 页](source-extracts/camera-spec-raw.md#pdf-page-001)、[第 2 页](source-extracts/camera-spec-raw.md#pdf-page-002)。

## 彩色型号像素格式

- Mono 8/10/12
- Bayer RG 8/10/10Packed/12/12Packed
- YUV422Packed、YUV422_YUYV_Packed
- RGB 8、BGR 8

本项目优先选择 **Mono 8**：几何测量只需要亮度边缘，Mono 8 可避免 Bayer 插值对边缘位置的影响，也减少带宽和处理量。需要彩色诊断时再临时切回 Bayer 或 BGR，不在同一测量配方中混用格式。

## 本项目推荐参数

| 节点/概念 | 初始值 | 原因 |
|---|---:|---|
| Pixel Format | Mono 8 | 直接用于灰度边缘，数据量小 |
| Width / Height | 2448 / 2048 | 保留完整几何分辨率 |
| Trigger Mode | On | 单次软件触发 |
| Trigger Source | Software | 静态人工放置，不需要外部触发 |
| Exposure Mode | Timed | 固定曝光时间 |
| Exposure Auto | Off | 避免帧间边缘灰度变化 |
| Exposure Time | 从 5000 µs 调起 | 静态目标可延长曝光，以降低增益 |
| Gain Auto | Off | 保持图像噪声稳定 |
| Gain | 0 dB 起 | 优先提高照明或曝光 |
| Gamma / LUT / Sharpness | Off | 避免改变边缘灰度剖面 |
| Binning / Decimation | 1×1 | 保留边缘点密度 |
| Reverse X / Y | Off | 避免配方坐标混乱 |

曝光初始值只是调试起点。最终应让目标边缘清晰、亮区不过曝、暗区仍有灰度层次，并保存到固定测量配方。

## 与角度精度有关的相机因素

- 全局快门消除了逐行曝光造成的运动几何畸变；本项目目标静止，仍应保持相机和支架稳定。
- 高增益会放大噪声并增加亚像素边缘抖动，优先增加曝光时间或改善照明。
- 改变相机 ROI、Binning、下采样或镜像后，原测量带坐标和标定文件可能失效。
- 相机温度变化会影响噪声和机械稳定性；固定安装并留出预热时间有利于重复性。
